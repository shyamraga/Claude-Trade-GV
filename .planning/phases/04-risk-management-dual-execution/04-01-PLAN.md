<objective>
Build the risk management system (circuit breakers, drawdown protection, 3-consecutive-loss 4-hour cooldown) and the automated trade loss post-mortem continuous learning memory.
</objective>

<tasks>
<task id="1">
<title>Define Risk Models & Circuit Breaker</title>
<action>
Create `src/risk/models.py` and `src/risk/circuit_breaker.py`:
- `RiskConfig`: max_daily_drawdown_pct, max_position_pct, stop_loss_pct, take_profit_pct, consecutive_loss_limit
- `CircuitBreaker`: monitors trades, tracks daily P&L, detects 3 consecutive losses, enforces 4-hour cooldown pause.
</action>
<acceptance_criteria>
- Circuit breaker trips when max daily drawdown or 3 consecutive losses occur
- Cooldown timer correctly blocks new trades for 4 hours unless overridden
</acceptance_criteria>
</task>

<task id="2">
<title>Implement Post-Mortem & Continuous Learning Memory</title>
<action>
Create `src/risk/post_mortem.py`:
- `TradePostMortem`: captures losing trade details, root-cause analysis, and preventative rule
- `PostMortemRepository`: saves post-mortems to markdown/json files and checks pre-trade filter against incoming signals.
</action>
<acceptance_criteria>
- Automatic post-mortem generation for losing trades
- Pre-trade filter warns or blocks trades matching past failure patterns
</acceptance_criteria>
</task>

<task id="3">
<title>Test Risk & Post-Mortem Systems</title>
<action>
Create `tests/test_risk.py`:
- Test circuit breaker drawdown trigger
- Test 3-consecutive-loss 4-hour cooldown
- Test post-mortem generation and pre-trade memory filter
- Execute with unittest.
</action>
<acceptance_criteria>
- `python -m unittest tests/test_risk.py` exits 0 with all tests passing
</acceptance_criteria>
</task>
</tasks>
