<objective>
Build the market data feed adapters for Alpaca Markets (primary real-time and historical) and Yahoo Finance (fallback and multi-timeframe supplement), with standardized data models.
</objective>

<tasks>
<task id="1">
<title>Create normalized data models for market data</title>
<read_first>
- .planning/phases/01-market-data-ingestion-storage/01-CONTEXT.md
</read_first>
<action>
Create `src/data/models.py` defining:
- Enum `TimeFrame`: `M1 = "1m"`, `M5 = "5m"`, `M15 = "15m"`, `H1 = "1h"`, `D1 = "1d"`
- Dataclass `Bar`: `symbol: str`, `timestamp: datetime`, `open: float`, `high: float`, `low: float`, `close: float`, `volume: float`, `vwap: Optional[float] = None`
- Dataclass `Quote`: `symbol: str`, `timestamp: datetime`, `bid_price: float`, `ask_price: float`, `bid_size: float`, `ask_size: float`
- Helper serialization methods: `to_dict()`, `from_dict()`.
</action>
<acceptance_criteria>
- `src/data/models.py` exists and can be imported without errors
- `Bar` and `Quote` dataclasses have type hints and serialize to/from dictionaries
</acceptance_criteria>
</task>

<task id="2">
<title>Implement Alpaca Market Data client</title>
<read_first>
- src/data/models.py
- .env
</read_first>
<action>
Create `src/data/alpaca_client.py` connecting to Alpaca Market Data v2 API (`https://data.alpaca.markets/v2`):
- Load `APCA_API_KEY_ID` and `APCA_API_SECRET_KEY` from environment / `.env`
- Method `get_bars(symbol: str, timeframe: TimeFrame, limit: int = 100, start: Optional[datetime] = None, end: Optional[datetime] = None) -> List[Bar]`
- Method `get_latest_bar(symbol: str) -> Optional[Bar]`
- Method `get_latest_quote(symbol: str) -> Optional[Quote]`
- Gracefully handle HTTP errors, rate limits, and network retries.
</action>
<acceptance_criteria>
- `src/data/alpaca_client.py` contains `AlpacaDataClient`
- Successfully connects to `https://data.alpaca.markets/v2/stocks/bars` with credentials
</acceptance_criteria>
</task>

<task id="3">
<title>Implement Yahoo Finance client and unified FeedManager</title>
<read_first>
- src/data/models.py
- src/data/alpaca_client.py
</read_first>
<action>
Create `src/data/yahoo_client.py` and `src/data/feed_manager.py`:
- `YahooDataClient`: Fetches OHLCV historical data using Yahoo Finance endpoints
- `FeedManager`: Facade coordinating Alpaca as primary and Yahoo as fallback provider:
  - `get_bars(symbol: str, timeframe: TimeFrame, limit: int = 100) -> List[Bar]`
  - `get_quote(symbol: str) -> Quote`
  - Automatic fallback if primary fails
</action>
<acceptance_criteria>
- `src/data/feed_manager.py` contains `FeedManager` class
- Fallback logic switches to Yahoo if Alpaca is unavailable or symbol is not supported
</acceptance_criteria>
</task>
