<objective>
Build local SQLite database storage for market data caching, tick logs, and watchlist tracking with high-performance indexing and querying.
</objective>

<tasks>
<task id="1">
<title>Initialize SQLite schema and connection manager</title>
<read_first>
- src/data/models.py
- .planning/phases/01-market-data-ingestion-storage/01-CONTEXT.md
</read_first>
<action>
Create `src/storage/db.py`:
- `Database`: Handles SQLite connection pooling, WAL mode (`PRAGMA journal_mode=WAL`), and synchronous setting for fast write throughput
- Schema definition:
  - `bars`: `(id INTEGER PRIMARY KEY, symbol TEXT, timeframe TEXT, timestamp TEXT, open REAL, high REAL, low REAL, close REAL, volume REAL, vwap REAL, UNIQUE(symbol, timeframe, timestamp))`
  - `watchlists`: `(id INTEGER PRIMARY KEY, symbol TEXT UNIQUE, added_at TEXT, active INTEGER DEFAULT 1)`
  - Index on `bars(symbol, timeframe, timestamp DESC)`.
</action>
<acceptance_criteria>
- `src/storage/db.py` creates tables and indices on startup
- Database operates in WAL mode with composite index
</acceptance_criteria>
</task>
