Build the financial news ingestion pipeline using NewsAPI.org to fetch real-time headlines for target stock symbols, with caching and error handling.
</objective>

<title>Define AI Data Models</title>
<read_first>
- .planning/phases/03-ai-sentiment-news-analysis/03-CONTEXT.md
</read_first>
<action>
Create `src/ai/models.py`:
- Dataclass `NewsArticle`: `symbol: str`, `title: str`, `description: Optional[str]`, `source: str`, `published_at: datetime`, `url: str`, `content_snippet: Optional[str]`
- Dataclass `SentimentAnalysis`: `symbol: str`, `sentiment: str` (bullish/bearish/neutral), `confidence: float` (0.0-1.0), `themes: List[str]`, `risks: List[str]`, `summary: str`, `analyzed_at: datetime`
- Dataclass `MarketContext`: `symbol: str`, `news_articles: List[NewsArticle]`, `sentiment: Optional[SentimentAnalysis]`, `cached_at: datetime`
</action>
<acceptance_criteria>

</acceptance_criteria>

<task id="2">
<title>Implement NewsAPI Client</title>
<read_first>
- src/ai/models.py
- .env
</read_first>
<action>
Create `src/ai/news_client.py`:
- Class `NewsAPIClient`:
  - Constructor loads `NEWS_API_KEY` from environment
  - Method `fetch_news(symbol: str, limit: int = 10) -> List[NewsArticle]`
  - Queries NewsAPI.org `/v2/everything` endpoint with `q={symbol} stock OR {company_name}` and `sortBy=publishedAt`
  - Parses JSON response into `NewsArticle` objects
  - Handles HTTP errors (401, 429, 500) with retry logic and exponential backoff
  - Implements in-memory LRU cache with 15-minute TTL per symbol
  - Method `clear_cache()` for testing
</action>
<acceptance_criteria>
- `src/ai/news_client.py` successfully fetches news for test symbols (AAPL, TSLA, SPY)
- Cache prevents duplicate API calls within TTL window
- Graceful degradation when API key is missing or rate limit exceeded
</acceptance_criteria>
</task>
