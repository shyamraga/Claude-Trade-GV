- src/ai/news_client.py
- .env
</read_first>
<action>
Create `src/ai/claude_analyzer.py`:
- Class `ClaudeAnalyzer`:
  - Constructor loads `ANTHROPIC_API_KEY` from environment
  - Method `analyze_news(articles: List[NewsArticle], symbol: str) -> SentimentAnalysis`
  - Constructs system prompt: "You are a financial analyst assessing market sentiment from news. Provide structured JSON output."
  - Constructs user prompt with article titles, descriptions, and sources
  - Calls Claude API (`/v1/messages`) requesting JSON output: `{"sentiment": "bullish|bearish|neutral", "confidence": 0.0-1.0, "themes": [], "risks": [], "summary": ""}`

  - Implements retry with exponential backoff for API errors (429, 500, 529)
  - Caches sentiment results per symbol for 30 minutes

<task id="2">
<title>Build Sentiment Scoring Aggregator</title>
<read_first>
- src/ai/models.py
- src/ai/claude_analyzer.py
</read_first>
<action>
Create `src/ai/sentiment_scorer.py`:
- Class `SentimentScorer`:
  - Method `aggregate_sentiment(analyses: List[SentimentAnalysis]) -> float` — returns weighted average confidence from multiple sentiment analyses
  - Method `modulate_signal_confidence(base_confidence: float, sentiment: SentimentAnalysis, action: SignalAction) -> float`:
    - If action is BUY and sentiment is bullish: boost confidence by 10-15%
    - If action is BUY and sentiment is bearish: reduce confidence by 15-20%
    - If action is EXIT and sentiment is bearish: boost confidence by 10%
    - If action is EXIT and sentiment is bullish: reduce confidence by 10%
    - Clamps result to [0.0, 1.0]
  - Method `get_trade_recommendation(symbol: str, sentiment: SentimentAnalysis) -> str` — returns human-readable trade recommendation
</action>
<acceptance_criteria>
- `src/ai/sentiment_scorer.py` correctly adjusts signal confidence based on sentiment
- All confidence values remain within valid 0.0-1.0 range after modulation
</acceptance_criteria>
</task>
