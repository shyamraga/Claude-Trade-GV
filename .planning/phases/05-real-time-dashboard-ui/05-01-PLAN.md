<objective>
Build a high-performance REST API backend using Python's standard http.server / FastAPI-compatible handlers to serve portfolio equity, positions, candlestick data, circuit breaker status, and post-mortems to the frontend dashboard.
</objective>

<tasks>
<task id="1">
<title>Implement Dashboard REST API Server</title>
<action>
Create `src/api/server.py`:
- `DashboardAPIHandler`:
  - `GET /api/account`: returns cash, equity, buying power, day trades count, mode
  - `GET /api/positions`: returns active positions and unrealized P&L
  - `GET /api/bars?symbol=AAPL&timeframe=15m`: returns OHLCV candle series
  - `GET /api/circuit-breaker`: returns cooldown status, daily drawdown, consecutive losses
  - `POST /api/circuit-breaker/override`: toggles manual override
  - `GET /api/trades`: returns completed trade history
  - `GET /api/post-mortems`: returns loss post-mortems and preventative rules
  - `POST /api/execute`: triggers manual or signal order execution
  - `POST /api/mode`: switches execution mode (VIRTUAL vs LIVE)
</action>
<acceptance_criteria>
- Clean JSON responses with proper headers and CORS
- Safe error handling and parameter validation
</acceptance_criteria>
</task>
