<action>
Create `src/indicators/calculator.py`:
- Class `IndicatorCalculator`:
  - `sma(data: List[float], period: int) -> List[Optional[float]]`
  - `ema(data: List[float], period: int) -> List[Optional[float]]`
  - `rsi(data: List[float], period: int = 14) -> List[Optional[float]]` (Wilder's smoothing)
  - `macd(data: List[float], fast_period: int = 12, slow_period: int = 26, signal_period: int = 9) -> MACDResult`
  - `bollinger_bands(data: List[float], period: int = 20, num_std: float = 2.0) -> BollingerBandsResult`
  - `atr(bars: List[Bar], period: int = 14) -> List[Optional[float]]`
  - `vwap(bars: List[Bar]) -> List[Optional[float]]`
  - `extract_closes(bars: List[Bar]) -> List[float]`
  - Robust handling for edge cases: `len(data) < period`, empty arrays, zero volume.
</action>
