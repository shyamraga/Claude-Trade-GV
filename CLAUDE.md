# Claude Trading Instructions

## Project

**Project: Claude Trading**

An intelligent, automated algorithmic trading and portfolio management platform powered by Claude AI.

- **Backend:** Python (pandas, numpy, ccxt, alpaca-py, requests)
- **Database:** SQLite / PostgreSQL
- **Frontend:** React, TypeScript, Tailwind CSS, Recharts
